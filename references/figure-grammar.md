# NJU-LINK 论文图表视觉语法

这是一份从公开样本反推的工作规范，不是 NJU-LINK 的官方设计系统。颜色值是从渲染后的页面和项目图中拟合的近似 token；当用户提供了原始 SVG、绘图脚本或精确参考图时，以用户材料覆盖本文件。

## 一句话风格

白底、近黑文字、低饱和多色 pastel、细线圆角模块、虚线分组边界、清晰的左到右信息流，以及“一个主结论 + 少量可读子图”的科研编辑感。图表可以很丰富，但每个颜色、图标和框线都承担分类、阶段或证据层级。

## 证据强度

| 特征 | 稳定性 | 观察依据 |
|---|---|---|
| 白底、近黑文字、浅色填充 | 高 | Q-Tuning、T2AV-Compass、DRIFT、CoVEBench、CodeTracer 等首页图与项目图 |
| pastel 类别色跨子图复用 | 高 | T2AV、DRIFT、CoVEBench 的环图、radar、bar、heatmap |
| 圆角卡片 + 细边框 + 虚线分组 | 高 | Q-Tuning、DRIFT、CoVEBench、CodeTracer 流程图 |
| 左到右流程、编号阶段 | 高 | Q-Tuning、FUNPOISON、TELBENCH、CoVEBench |
| 旭日/环图/雷达承担总览 | 中高 | T2AV、DRIFT、CoVEBench、CONTEXTBENCH |
| 手绘/emoji/工具图标 | 中 | FUNPOISON、CoVEBench、Agentic-MME、CodeTracer；与具体作者或软件包有关 |
| NJU-LINK wordmark | 中 | T2AV、DRIFT、CodeTracer 论文首页；不是所有论文都有 |
| 具体字体名 | 低 | PDF 中混有 URW Palladio/Times、Arial/Calibri、DejaVu Sans、Chalkboard 等，不能假定单一字体 |

## 颜色 token

下面的 hex 是“风格近似”，用于新图的统一视觉，不表示原论文使用了同一组精确 RGB。

### 基础色

| Token | Hex | 用途 |
|---|---|---|
| `ink` | `#242424` | 标题、正文、主轮廓、主箭头 |
| `ink-muted` | `#686868` | 次要标签、轴、注释 |
| `line` | `#7F7F7F` | 细边框、分组虚线 |
| `grid` | `#D8D8D8` | 网格、雷达圈、弱分隔线 |
| `paper` | `#FFFFFF` | 画布与卡片底色 |
| `panel` | `#FAFAF8` | 大面板的近白底 |

### Pastel 类别循环

```text
teal       #57BDB5
sky        #85B9E2
lavender   #B6A4D8
rose       #E5A1AF
coral      #F39A83
peach      #F4C6A5
mustard    #E6C35C
sage       #A9C995
```

### 浅色填充与强调色

对模块背景使用同色 12–24% 不透明度，边框使用原色或降低亮度 10–20%。需要“错误/危险”时用 `#D95F5F`，需要“通过/保留”时用 `#58A889`，但同时加文字、符号或线型；不要只依赖红绿。

### 颜色使用规则

1. 同一语义在所有子图保持同一色；
2. 每个面板最多 5–6 个同时出现的高饱和类别，超过时分层或使用灰度；
3. 对连续变量使用单调亮度序列，避免把类别色当热度图；
4. 颜色只承担一个主要含义：阶段、类别、模型或状态四选一；
5. 彩色填充配近黑文字或白底标签，保证缩小后仍可读。

## 线、边框与几何

| 元素 | 建议值 |
|---|---|
| 模块圆角 | 8–12 px（Matplotlib 以 points 近似） |
| 模块边框 | 1.2–1.6 pt，圆角，颜色为 `line` 或语义色 |
| 分组边界 | 1.0–1.3 pt，`(0, (4, 3))` 虚线 |
| 主箭头 | 1.4–1.8 pt，填充三角箭头，颜色 `ink` |
| 次连接线 | 0.9–1.2 pt，颜色 `ink-muted` |
| 图表轴 | 0.7–0.9 pt，尽量保留左/下轴或只保留基线 |
| 网格 | 0.5–0.7 pt，`grid`，透明度 0.45–0.7 |
| 面板间距 | 8–18 px；保持列/行基线一致 |
| 外边距 | 图宽的 4–7%；图注另留 4–8 pt |

箭头优先直线或正交折线，方向从左到右或从上到下；跨越线要减少。用黑色圆形编号或彩色徽章标出阶段，编号必须按阅读顺序递增。

## 字体与文字层级

论文正文通常由 LaTeX 模板决定；图内标签应自带可移植的字体回退。默认使用 `DejaVu Sans` 或 `Arial` 类无衬线，数学字符使用 Matplotlib mathtext；用户环境有字体时再切换到 Calibri/Helvetica。不要依赖 Chalkboard、AppleColorEmoji 或本地私有字体作为唯一回退。

| 层级 | 典型大小（最终图宽 6.5–7.0 in） | 处理 |
|---|---:|---|
| 图内总标题 | 10–12 pt | 句首大写/短语，粗体，可省略以交给 caption |
| 子图标题与阶段标签 | 8.5–10 pt | 粗体或半粗，短动词短语 |
| 面板标签 `(a)` | 9–10 pt | 粗体，固定放左上角 |
| 轴、图例、节点文字 | 7–8.5 pt | 不超过一到两行，必要时换行 |
| 数据注释 | 6.5–7.5 pt | 只标关键值，避免每个点都贴标签 |
| 代码/伪代码 | 7–8 pt | 等宽字体，浅色背景，少量高亮 |

使用句首大写和短标签；过程图的文字回答“输入/动作/输出”，而不是完整段落。一个面板内不要混用超过两种字体。

## 五种骨架

### A. 模块化流程图

适合数据构建、agent pipeline、训练/推理框架。

```text
[数据源] → [筛选/变换] → [模型/工具] → [检查/评测] → [输出]
```

- 3–6 个主阶段；每阶段一个圆角容器；
- 容器上沿放 `(1)`、`(2)` 等编号与短标题；
- 输入和输出用更明确的色框，内部细节用图标 + 2–5 个词；
- 重要分支用同色浅底，不用粗黑边；
- “人工/LLM/工具”用小图标区分，旁边保留文字标签，避免图标猜谜。

### B. 总览环图/旭日/玫瑰

适合类别层级、任务覆盖、错误族谱和数据分布。

- 中心放主题短词或 logo 替代文本；
- 第一层用 5–8 个主色块，第二层降低饱和度或提高亮度；
- 分区边界 0.8–1.2 pt 白色或近白色；
- 标签沿扇区方向但保持最小可读角度，过密时移到图例；
- 旁侧可放 2–4 个小图（bar/line/heatmap），共享颜色映射。

### C. Radar / 极坐标比较

适合多维能力或模型覆盖。

- 背景透明或白色，圆形网格使用浅灰；
- 每个模型使用一条 1.4–1.8 pt 线，填充透明度 0.05–0.14；
- 颜色最多 6 个，模型较多时用小倍数面板而不是叠 10 条线；
- 轴标签沿圆周，必要时用两层标签或外置图例；
- 标准化、方向和范围写进图注或小标题。

### D. 机制/错误分析矩阵

适合错误族谱、阶段—故障热图和模型对照。

- 热图用连续/发散色，数值写入格内但不超过 2–3 位有效数字；
- 右侧放一个小散点、频率图或 high-frequency/high-error 解释图；
- 类别色在 sunburst、bar、heatmap 的行标中保持一致；
- 空白和浅色表示低频/无样本，不能与缺失值混淆。

### E. 定性案例面板

适合视频编辑、视觉工具调用、跨模态验证。

- 原始帧、生成帧和预期结果用不同但同组色框；
- filmstrip 用统一帧宽、等间距、虚线短分隔；
- 重要区域用细色框、箭头或编号，不要用厚红圈覆盖主体；
- 评分、错误和保真度放在侧栏，颜色与指标名称一一对应；
- 图中只保留能证明结论的案例，完整样例放附录或链接。

## 图表组件规范

### Bar / line

- 柱宽约为组间距的 0.55–0.70；
- 坐标轴只保留必要刻度，主网格透明度 0.45；
- 高亮柱使用语义色，其他柱降为灰或同色浅色；
- 折线用圆角 marker，小于 6 条线时才直接标注；
- 误差线使用相同颜色、0.9–1.2 pt 和小端帽。

### Table

- 白底、浅灰/浅绿表头、最少竖线；
- 最优值粗体，第二名可用下划线或浅色底；
- `✓` / `×` / `–` 用颜色 + 文字冗余编码；
- 表格文字 6.5–8 pt，列标题尽量分组换行。

### Heatmap

- 单元格边界 0.4–0.7 pt，防止相邻色块糊成一片；
- 文本颜色根据亮度自动切换近黑/白；
- 颜色条给出单位、范围和方向，不把“越高越好”留给读者猜；
- 低频或未知值用斜线/`n/a`，不要使用与低值相同的淡色。

### 图标与图片

- 采用单线、扁平、少细节的图标；
- 统一描边粗细和圆角；
- 图标只说明实体/动作，定量信息交给图表；
- 不能使用原论文独家图标时，用同语义的几何符号或公开许可图标替代。

## 可复现导出

推荐最终图宽 6.5–7.0 in（双栏跨栏），单栏 3.2–3.5 in；PNG 300 dpi，矢量版 PDF/SVG。使用 `bbox_inches="tight"` 时预留 `pad_inches=0.08–0.12`，避免标题和图例贴边。固定随机种子、数据排序、颜色顺序和字体回退；把这些参数写进脚本顶部或 JSON 配置。

## 反模式

- 默认蓝橙配色、厚黑边、深色背景、3D 饼图、阴影和渐变；
- 同一颜色在不同子图表示不同类别；
- 一张图同时塞流程、结论、消融和所有结果，却没有主阅读路径；
- 用图标替代文字或把整段方法写在圆角框里；
- 直接截取/重绘原图并去掉来源、把共同作者图表称为个人专属签名；
- 只在大画布上清晰，缩到论文栏宽后标签、线和图例不可读。
