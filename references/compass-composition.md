# T2AV 风格综合构图

适用于借鉴 T2AV-Compass 的多模态评测总览。先看 [综合成图](../examples/njulink-style-demo.png) 和 [官方参考](t2av-compass.md)，再使用 [compass_panels.py](../scripts/compass_panels.py)。这个构图是一个具体选项；不要把不相关的研究问题硬塞进相同的环图。

## 六部件如何对应参考

| 部件 | 参考中可观察的做法 | 本示例实现 |
|---|---|---|
| 布局 | 主图约 2.65:1，左径向、中统计、右层级 | 三列约 32% / 34% / 31%，列间留白；综合图上方另加紧凑流程 |
| 元素 | 各方向成组窄条；密度图；横向条；多环 taxonomy | 七方向六模型；同一表生成径向值与两组横条；三层 21 叶任务树 |
| 颜色 | 模型色在同一比较任务里复用，任务层级有自己的色族 | 六模型固定颜色；任务环图子类沿用父色相并逐级变浅 |
| 字体 | 官方 radar SVG 的字形 ID 明确含 `Chalkboard-*` | 默认寻找已安装 Chalkboard；固定可移植模式使用随库分发的 Comic Neue |
| 流程细节 | 双源支路、虚线容器、具体模态图像、审核符号 | 原创三帧场景、示意波形、聚类散点、结构化描述、勾选项、数据库 |
| 图例与标注 | 中心主题明确、图例贴近数据、底部短图注 | 径向图下方两行图例；旋转标签保持正向；长标签使用明确缩写 |

## 尺寸和字体

`demo.py` 默认画布 7.2 × 4.12 in（约 183 × 105 mm），横版 `t2av_style_demo.py` 为 7.2 × 2.80 in。PNG 输出 450 dpi，PDF 保留矢量对象并嵌入使用的字形，SVG 将字形转成路径以避免查看端字体替换。

标题约 7.4–8 pt，流程正文约 6.5 pt，环图叶标签 5.1 pt、径向数字 5.4 pt。这些密集标注适合跨双栏总览；如果目标模板要求至少 6 pt，拆出单独的 taxonomy/结果图并放大，不要把整个综合图缩进单栏。验收同时查看原尺寸和约 1080 px 宽的预览。

```bash
python scripts/demo.py --output-dir figures/base
python scripts/t2av_style_demo.py --output-dir figures/overview
python scripts/demo.py --font portable --output-dir figures/portable
```

`--font reference` 用本机已有的 Chalkboard；不存在时使用 Comic Neue。`--font portable` 始终使用仓库字体。两种模式都应检查标签；字体选择会写入输出 JSON。OFL 许可和文件哈希见 [字体清单](demo-fonts.json)。

## 数据与科学含义

可编辑数据在 [assets/compass-demo.json](../assets/compass-demo.json)。六个模型、七个维度、色值、分数和层级标签都集中在这里。总览图不会另外手写一份“差不多”的结果。

- 分数是合成的通过率，每维 100 个测试，所有轴都是 0–100、越高越好。径向条从中心盘之外的公共基线出发，条长编码通过率；灰色轨道代表满分长度。
- 两张横条图直接读取径向图的 Video match / Audio match 列。固定模型顺序和颜色，方便逐行比较，不分别排序。
- 提示词长度按固定种子生成三组各 700 个正整数；高斯 KDE 使用 Scott 带宽、在零点反射。纵轴是真正的概率密度，不把三个峰值任意缩放到同一高度。实际样本写入输出 JSON。
- 三层环图给每个叶节点相同角度；各父级角度是子级之和。面积不代表样本数量或模型成绩。
- 帧带和波形是流程中的原创示意符号，不是视频生成结果或音频测量。所有画面内的模拟标签保留到替换真实数据为止。

## 视觉验收和差异

先检查留白与面板占比，再看字体和局部细节。逐一排查旋转标签是否倒置、文字是否跨环、图例是否压住图注、密度图横轴标题是否碰到下方条图标题。只验证脚本退出成功无法发现这些问题。

当前成图保留 T2AV 的三列信息组织、Chalkboard 字体和轻边框部件，重新设计了流程、中心图案、配色与任务树；没有复现其 logo、真实视频截图、具体数据或所有渐变装饰。这是可复用的独立成图，不是原图的像素复刻。
